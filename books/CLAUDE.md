## What this is

EPUB files the app offers on its "Free classics" shelf, listed in `manifest.json` (`id`, `title`, `author`, `file`, optional `note`). **Only texts that are public domain in the US, both the original and the Spanish translation, ever go here** — this folder is published on GitHub Pages.

## Conventions specific to this project

- Gutenberg files are numbered `pg<n>.epub`. The Wikisource ones come from `https://ws-export.wmcloud.org/?lang=es&page=<title>&format=epub-3`.
- Never add a copyrighted book. Brian's own purchases are loaded on his phone and never committed.
