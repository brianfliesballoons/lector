## What this is

EPUB files the app offers on its "Free classics" shelf, listed in `manifest.json` (`id`, `title`, `author`, `file`, optional `note`). **Only texts that are public domain in the US, both the original and the Spanish translation, ever go here** — this folder is published on GitHub Pages.
